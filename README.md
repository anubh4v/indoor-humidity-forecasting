# Humidity Forecasting — M.Tech Thesis (CSE)

**Forecasting Indoor Relative Humidity and Mite-Favourable Conditions in Low-Income South Asian Housing**

This repository contains the data-processing and machine-learning pipeline used in the above M.Tech (Computer Science and Engineering) thesis. All analysis is implemented in Python 3.

---

## Folder Structure

```
Analysis/
├── predictive_modeling.py     # Main ML pipeline: features → models → results (Random Forest vs Linear vs Persistence)
├── requirements.txt           # Python dependencies
│
├── Yavatmal/                  # Rural Maharashtra, India (2 RH households)
│   ├── Yavatmal Indoor Data.csv       # cleaned indoor sensor data (10-min RH + temperature)
│   ├── Yavatmal AWS Data.csv          # cleaned outdoor weather-station data (hourly)
│   ├── humidity_analysis.py           # descriptive plots: hourly averages, monthly boxplots, time series
│   ├── indoor_vs_outdoor.py           # indoor–outdoor correlation (hexbin) + longitudinal comparison
│   └── *.png                          # generated figures
│
├── Faisalabad/                # Urban Pakistan (3 RH households)
├── Dhaka/                     # Urban Bangladesh (6 RH households)
├── Jalna/                     # Rural Maharashtra, India (1 RH household)
└── Delhi/                     # Urban India (5 RH households)
```

Each city folder follows the same pattern: cleaned indoor CSV (one column per household sensor, `(RH)` columns are relative humidity), cleaned AWS (weather station) CSV, and the analysis scripts that generate the figures.

---

## Original Data Source

The raw sensor data come from the open-access dataset:

> Tasgaonkar, P., Zade, D., Ehsan, S., et al. (2022). *Indoor heat measurement data from low-income households in rural and urban South Asia.* Scientific Data, 9, 285. DOI: [10.6084/m9.figshare.12546368](https://doi.org/10.6084/m9.figshare.12546368)

The CSVs in this repository are **cleaned and processed** versions of that data (standardised date/time formats, empty rows removed, sparse households filtered, resampled to daily means where noted). Please cite the original dataset when using the data.

## Reproducing the Analysis

### 1. Descriptive analysis (per city)

Run from inside a city folder:

```bash
python humidity_analysis.py      # generates hourly_average_humidity.png, monthly_humidity_boxplot.png, humidity_over_time.png
python indoor_vs_outdoor.py      # generates hexbin correlation plots + indoor_vs_outdoor_humidity.png
```

A `Data cleaning script.py` example (Dhaka) shows the date/time standardisation step.

### 2. Predictive modeling (forecasting chapter)

From the `Analysis/` root:

```bash
python predictive_modeling.py
```

This runs the full experiment described in the thesis:

- Builds the daily feature set (lagged indoor RH t-1/t-2/t-7, current + lagged outdoor RH, monsoon flag, month, city, household)
- Trains persistence (baseline), linear regression, and Random Forest (100 trees, fixed seed)
- Splits each city temporally: train on first 80% of days, test on the last 20% (no random shuffling — avoids data leakage)
- Reports metrics per city and pooled: MAE, RMSE, R² (regression); accuracy, precision, recall, F1 (mite-favourable classification)
- Saves:
  - `results_overall.csv` — pooled model comparison
  - `results_per_city.csv` — per-city Random Forest performance
  - `feature_importance.png` — Random Forest feature importance
  - `baseline_comparison.png` — R² comparison across models
  - `predicted_vs_actual.png` — forecast vs actual for the best city
  - `random_forest_model.pkl` — saved model (regenerated by the script; not tracked in git)

The Random Forest is trained with `random_state=42`, so results are fully reproducible.

## Key Results (for reference)

| Model | MAE (%) | RMSE (%) | R² |
|---|---|---|---|
| Persistence | 3.96 | 6.66 | 0.833 |
| Linear Regression | 3.41 | 5.16 | 0.900 |
| Random Forest | 3.48 | 5.42 | 0.890 |

Per-city (Random Forest, test set): Delhi R² 0.901, Dhaka 0.696, Faisalabad 0.589, Jalna 0.151, Yavatmal 0.728.

## Notes

- The mite-favourable index is a **proxy** derived from humidity thresholds (<50% less favourable, 50–65% moderately favourable, >65% highly favourable), per the dust-mite literature (Arlian et al., 1975). This dataset contains no direct mite measurements.
- The raw dataset files are **not** redistributed here; only the cleaned, processed versions are included. Please cite the original dataset above.
- Issues or questions welcome via GitHub issues.
